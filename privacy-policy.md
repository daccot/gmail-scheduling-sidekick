# Privacy Policy for Gmail Scheduling Sidekick

Last updated: 2026-04-25

Gmail Scheduling Sidekick helps generate scheduling candidates, email templates, local work memos, and Google Calendar event creation links.

## Data collection

This extension does not collect, sell, transmit, or share personal data.

## Gmail content

The extension can insert user-generated text into an open Gmail compose/reply box.
It does not transmit Gmail message contents to external servers.

## Calendar content

The extension opens Google Calendar event creation URLs.
It does not read Google Calendar event details.

## Local storage

Settings, memo text, and diagnostic logs are stored using Chrome extension storage.

## Network communication

The extension does not send data to external servers operated by the developer.
