# Product Roadmap

## v0.6.0

Current baseline:

- TypeScript project structure
- Japanese/English language selection
- Auto language based on browser setting
- Gmail side panel
- Candidate generation
- Reply templates
- Gmail insertion
- Local memo
- Calendar event creation links

## v0.7.0: UX polish

- Improve candidate editing
- Add preset time patterns
- Add compact view
- Add first-run onboarding
- Add screenshot-ready UI
- Remove unused permissions if possible

## v0.8.0: Template system

- Custom templates
- Template variables
- Save frequently used phrases
- Per-language template editing
- Import/export settings

## v0.9.0: Thread-aware workflow

- Save memo by Gmail thread
- Detect subject and recipient context
- Show recent scheduling drafts
- Candidate history

## v1.0.0: Store-ready stable release

- Permissions audit
- Privacy policy finalization
- Store listing finalization
- Screenshots
- QA checklist
- Public release tag

## v1.1+: Calendar API option

- OAuth integration
- Read free/busy availability
- Auto-create tentative holds
- Delete unused tentative holds
- Confirm selected slot

## Long-term differentiation

The winning product is not "a sidebar."

The winning product is:

> A scheduling workflow assistant embedded in Gmail.
