# Monetization Plan

## Product principle

Do not charge for a generic sidebar.

Charge only when the extension saves clear scheduling work:
- fewer copy/paste steps
- faster reply creation
- fewer missed tentative holds
- less context switching

## Target users

### Primary

People who coordinate meetings from Gmail:
- recruiters
- salespeople
- consultants
- customer success
- freelance workers
- internal coordinators
- interview candidates

### Secondary

Japanese business users who want polite scheduling replies.

## Free version

Keep the free version useful enough to prove value:

- Candidate time generation
- Manual candidate addition
- Basic reply templates
- Gmail insertion
- Local memo
- Calendar event creation links
- Japanese/English UI

## Paid version ideas

### Pro: Scheduling automation

Possible price:
- $2.99/month
- $19/year
- ¥300/month
- ¥2,000/year

Features:
- Custom templates
- Saved scheduling presets
- Per-contact memo history
- Thread-specific memo
- More candidate patterns
- One-click candidate reuse
- Export/import settings

### Pro Plus: Calendar intelligence

Possible price:
- $5.99/month
- $49/year
- ¥600/month
- ¥5,000/year

Features:
- Google Calendar API integration
- Real availability check
- Auto-create tentative holds
- Remove unselected tentative holds
- Detect confirmed time from reply text
- Multi-calendar support

This requires OAuth and a more careful privacy review.

## Enterprise angle

For company use:
- Admin default templates
- Shared business-hour rules
- Japanese/English template sets
- Exportable audit notes
- Internal scheduling style guide

Possible pricing:
- $2/user/month
- minimum 10 users
- annual billing

## Do not monetize too early

Avoid charging before these are stable:
- Gmail insertion
- candidate generation
- Calendar hold workflow
- language switching
- data handling explanation

## First monetization milestone

Charge only after adding at least one of:

1. Custom saved templates
2. Thread-specific memo
3. Calendar API availability check
4. Auto tentative hold creation
5. Reply text detection

## Recommended path

1. Free Chrome extension
2. GitHub public repo
3. Chrome Web Store release
4. Collect feedback
5. Add Pro: custom templates and presets
6. Add Pro Plus: Calendar API
